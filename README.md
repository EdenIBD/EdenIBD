## Selected projects

### AI & information retrieval

**[Financial Report Analyzer](https://github.com/EdenIBD/financial-report-analyzer)**  
A RAG application for exploring SEC filings with cited answers. It combines document ingestion, scoped retrieval and a LangGraph workflow, with evaluation and documented limitations.  
`Python` `FastAPI` `LangGraph` `PostgreSQL` `Qdrant` `Next.js`

**[FoodGraph KG Assistant](https://github.com/EdenIBD/meal-mapper)**  
A team project that turns a snapshot of Open Food Facts into a queryable knowledge graph, with source-backed product exploration and recipe workflows.

**[Bioenergetics RAG](https://github.com/EdenIBD/rag-bioenergetics)**  
A document Q&A experiment exploring chunking, retrieval, reranking and grounded responses, with notebooks examining metrics and failure cases.  
`Python` `Qdrant` `Next.js`
